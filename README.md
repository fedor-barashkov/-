# Заполнение путевых листов

Проект для Lexus LX 470 (2000 г.), бензин + ГБО пропан; Якутия/Сибирь. Один водитель, один агент.

## Состояние проекта
Подготовлена структура репозитория и интерфейс ввода. Заполнение оригинального шаблона формы № 3 пока НЕ реализовано: требуется исходный файл бланка и образец заполнения. Новая форма вместо исходного шаблона не создаётся.

Источник бланка, указанный заказчиком:
https://nalog-nalog.ru/blanks/blank-putevogo-lista-legkovogo-avtomobilya/

## Запуск
Откройте index.html в браузере. Введите данные и нажмите «Сохранить входные данные». Полученный JSON содержит исходные значения, а не готовый путевой лист.

## Требования
- Пробег рассчитывается по израсходованному топливу и подтверждённым нормам, а не вводится как исходная величина.
- Накладные показывают поступление топлива: для расхода нужны остатки на начало и конец периода.
- Нормы расхода и региональные надбавки пока не проверены и не установлены.
- Метод совместного учёта бензина и газа должен быть согласован. Старый выбор максимума из двух пробегов исключён.
- Распределение по Пн–Пт; обработку праздников, исключений и округления нужно реализовать отдельно.
- Исходный бланк должен сохраняться без изменения структуры, включая оборотную сторону.
- Медосмотры, техконтроль, подписи, время и одометр нельзя выдумывать.

## Файлы
- index.html — форма сбора данных.
- app.js — сохранение данных в JSON.
- styles.css — оформление интерфейса, не печатного бланка.
- templates/README.md — инструкции по исходному шаблону.
- docs/TASKS.md — план реализации.
